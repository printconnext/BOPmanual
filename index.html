เริ่มต้น

ภาพรวมระบบ & การเข้าสู่ระบบ

BOP Express เป็นระบบบริหารงานขนส่งสินค้าระหว่างประเทศ (freight forwarding) แบบครบวงจร ครอบคลุมตั้งแต่การเสนอราคา → เปิดงานชิปเมนต์ → จัดการเอกสาร/พิธีการศุลกากร → การเงิน/เบิกจ่าย → ออกใบแจ้งหนี้และเอกสารภาษี

การเข้าสู่ระบบ
  1. เปิดเบราว์เซอร์ไปที่ https://bopexpress.online/backend/login
  2. กรอกอีเมล/ชื่อผู้ใช้ และรหัสผ่านของคุณ แล้วกดเข้าสู่ระบบ
  3. เมื่อเข้าสำเร็จจะพบ Operations Dashboard เป็นหน้าแรก
  • เมนูด้านซ้าย แบ่งเป็น 4 หมวด: OPERATIONS, FINANCE, MASTER DATA, ADMINISTRATION (กดปุ่มลูกศรบนแถบเมนูเพื่อย่อ/ขยายได้)
  • มุมขวาบน แสดงชื่อผู้ใช้และบทบาท (เช่น Super Admin) พร้อมปุ่ม Profile และ Logout
  • วันที่ ในเอกสารส่วนใหญ่แสดงเป็น พ.ศ. (เช่น 15/07/2569)
โมดูล CRM (ภาษาไทย) หน้าในกลุ่ม CRM (แดชบอร์ด CRM, ทะเบียนลูกค้า CRM, กระบวนการขาย) เป็นส่วนที่พัฒนาใหม่ ใช้ภาษาไทยเป็นหลัก และมีปุ่มสลับภาษา TH / EN ที่มุมขวาบนของแต่ละหน้า

ขั้นตอนการทำงานหลัก (Workflow)

ลำดับงานหลักของระบบเชื่อมโยงกันดังนี้

  1. ใบเสนอราคา (Quotation) — สร้างใบเสนอราคาให้ลูกค้า ระบุประเภทงานและรายการค่าบริการ
  2. Quotation Activities — ใส่รายละเอียดต้นทุน/กิจกรรมย่อย แล้ว ส่งอนุมัติ
  3. ใบสั่งขาย (Sales Order) — สร้างจากใบเสนอราคาที่อนุมัติแล้ว
  4. งานชิปเมนต์ (Shipment Job) — เปิดงานจากใบเสนอราคาที่อนุมัติ จัดการเอกสาร ตู้ พิธีการศุลกากร
  5. การเงิน (เบิกเงินทดรอง) — เบิกเงิน → อนุมัติเงิน → จ่ายเงิน → เคลียร์เงิน และบันทึก Shipment Expenses
  6. ออกใบแจ้งหนี้ — Sales Invoices / Shipment Invoices แล้วออกใบเสร็จ/ใบกำกับภาษี (Tax Documents)

Master Data เป็นข้อมูลตั้งต้นที่ป้อนให้ dropdown ทุกหน้า (ลูกค้า, ผู้ขาย, สินค้า/บริการ, ท่าเรือ ฯลฯ) และ Administration ควบคุมผู้ใช้/สิทธิ์/สถานะ/การตั้งค่าระบบ

หมวด Operations

1.Dashboard

/backend/dashboardภาพรวมงาน

หน้าสรุปภาพรวมงานปฏิบัติการ (Operations Dashboard) เห็นสถานะงานสำคัญได้ในหน้าเดียว

สิ่งที่แสดง
  • การ์ดตัวเลข (KPI): ALL JOBS, IMPORT, EXPORT, ETA IN 3 DAYS, MISSING DOCUMENTS, CUSTOMS PENDING
  • ปุ่ม Open Shipment Workspace — เข้าสู่พื้นที่จัดการงานชิปเมนต์
  • Latest Documents — เอกสารที่อัปโหลดล่าสุด (Job No / Type / File) พร้อมลิงก์ Missing docs report
  • Latest Status Changes — การเปลี่ยนสถานะล่าสุด พร้อมลิงก์ Audit log

2.CRM Dashboard — แดชบอร์ด CRM

/backend/crmCRM

ภาพรวมกระบวนการขายและงานติดตาม — สรุปสถานะ Inquiry (โอกาสการขาย) ทั้งหมดในหน้าเดียว

  • การ์ดตัวเลข (KPI): งานที่กำลังดำเนินการ, งานติดตามเกินกำหนด, ส่งใบเสนอราคาแล้ว, ปิดการขายสำเร็จ
  • ปุ่ม + สร้าง Inquiry — เปิดโอกาสการขาย/คำถามลูกค้ารายการใหม่
  • ปุ่มสลับภาษา TH / EN (มุมขวาบน) — โมดูล CRM รองรับทั้งไทยและอังกฤษ
  • แผง "Inquiry ล่าสุด" — ตารางล่าสุด: เลขที่, ลูกค้า, รูปแบบขนส่ง, สถานะ, วันติดตาม พร้อมลิงก์ ดูทั้งหมด ไปหน้ากระบวนการขาย

3.CRM Customers — ทะเบียนลูกค้า CRM

/backend/crm/customersCRM

ข้อมูลลูกค้า ผู้ติดต่อ ทีมดูแล และบริษัทผู้ดำเนินงาน — มุมมองลูกค้าแบบ 360°

วิธีใช้
  1. ใช้ช่อง ค้นหา หาด้วยชื่อลูกค้า, รหัส หรือรายละเอียด
  2. กดปุ่ม ข้อมูลลูกค้า 360° ที่แถวของลูกค้าเพื่อดูรายละเอียดเชิงลึก (ผู้ติดต่อ ทีมดูแล เอกสาร)
  3. กดปุ่ม สร้างลูกค้า (มุมขวาบน) เพื่อเพิ่มลูกค้าใหม่
  4. มีปุ่มสลับภาษา TH / EN เช่นเดียวกับหน้า CRM อื่น

คอลัมน์: CODE, ลูกค้า, ผู้ติดต่อ, โทรศัพท์, สถานะ

4.Inquiry Pipeline — กระบวนการขาย

/backend/crm/inquiriesCRM

กระดานติดตาม "Inquiry" (คำถาม/โอกาสการขายจากลูกค้า) ตั้งแต่รับเรื่องจนถึงส่งราคาและปิดการขาย

Inquiry Pipeline คือระบบอะไร? เป็น กระบวนการขาย (sales pipeline) ต้นทางของงานขาย — ทุกครั้งที่ลูกค้าติดต่อสอบถามงานขนส่ง จะเปิดเป็น "Inquiry" หนึ่งรายการ แล้วติดตามความคืบหน้าไล่ตามสถานะจนกลายเป็นใบเสนอราคาและปิดการขาย เชื่อมต่อกับหน้า Quotations โดยตรง (Inquiry → ใบเสนอราคา)
วิธีใช้
  1. กด + สร้าง Inquiry เพื่อเปิดโอกาสการขายใหม่ (ระบุลูกค้า รูปแบบขนส่ง ความเร่งด่วน)
  2. ใช้ช่อง ค้นหา (เลข Inquiry / ลูกค้า / รายละเอียดงาน) และตัวกรอง สถานะ หรือติ๊ก เฉพาะงานเกินกำหนด แล้วกด กรอง
  3. อัปเดตสถานะแต่ละ Inquiry ไล่ตามขั้นตอนการขาย
สถานะในกระบวนการขาย
รับเรื่องใหม่คัดกรองขอราคากำลังจัดทำใบเสนอราคาส่งใบเสนอราคาแล้วติดตามลูกค้าชนะแพ้ยกเลิกพักงาน

คอลัมน์: เลขที่, ลูกค้า, วันที่, ความเร่งด่วน, รูปแบบขนส่ง, สถานะ, ขั้นตอนถัดไป/วันติดตาม

5.Quotations — ใบเสนอราคา

/backend/quotationงานขาย

รายการใบเสนอราคาทั้งหมด และจุดเริ่มต้นของกระบวนการขาย

หน้ารายการ
  • คอลัมน์: เลขที่ (เช่น QT2026070004), วันที่, ลูกค้า, ยอดรวม, สถานะ
  • สถานะ: แบบร่าง ส่งแล้ว หมดอายุ
  • ปุ่มในแต่ละแถว: ดู (👁), แก้ไข ✏ (เฉพาะแบบร่าง), ลบ 🗑 (เฉพาะแบบร่าง), พิมพ์ 🖨
การสร้างใบเสนอราคา (ปุ่ม + สร้างใบเสนอราคา)
  • เลขที่ใบเสนอราคา — สร้างอัตโนมัติ
  • วันที่ * และ ใช้ได้ถึง * — วันที่ออกและวันหมดอายุ
  • ลูกค้า * — เลือกจากรายชื่อลูกค้า
  • เรื่อง — หัวข้อ/รายละเอียดงาน
  • ประเภทงาน — เลือก 1 ประเภท
  • ข้อมูลประกอบการเสนอราคา (BOP checklist) — สรุป requirement ก่อนคิดราคา เช่น ประเภทธุรกิจ, สิทธิประโยชน์ที่ถือครอง
  • รายการสินค้า/บริการ — เพิ่มรายการค่าบริการจากแค็ตตาล็อก (ดูหัวข้อ Products)
  • สรุปยอด (แผงขวา): ยอดรวม, ส่วนลด %, หลังหักส่วนลด, VAT % (ค่าเริ่มต้น 7), ภาษีมูลค่าเพิ่ม, ยอดสุทธิ

ปุ่ม: โหลดตัวอย่างงาน BOP / บันทึก / บันทึกใบเสนอราคา / ยกเลิก

6.Quotation Activities

/backend/quotation/activitiesงานขาย

จัดการรายการย่อย/โน้ต และต้นทุนของแต่ละใบเสนอราคา พร้อมส่งอนุมัติ

  1. เลือกใบเสนอราคาจาก dropdown Quotation
  2. ในตารางแต่ละรายการจะเห็น ประมาณการ/ต้นทุนจริง (Plan vs Actual) — กดปุ่ม + เพื่อเพิ่มต้นทุนหรือกิจกรรมย่อย
  3. กด ส่งอนุมัติ / Submit approval เมื่อพร้อม, หรือ จัดการ Templates เพื่อใช้เทมเพลตซ้ำ
หมายเหตุงานชิปเมนต์ควรเริ่มจากใบเสนอราคาที่ผ่านการอนุมัติแล้วเท่านั้น

7.Sales Orders — ใบสั่งขาย

/backend/sales/ordersงานขาย

เอกสารใบสั่งขายที่สร้างจากใบเสนอราคาที่อนุมัติแล้ว หรือสร้างเองแบบ manual

  • คอลัมน์: เลขที่ (เช่น SO2026030001), วันที่, ลูกค้า, ยอดรวม, สถานะ
  • กดปุ่ม + สร้างใบสั่งขาย เพื่อเพิ่มรายการใหม่ และปุ่มดู (👁) ที่แต่ละแถว

8.Sales Invoices — ใบแจ้งหนี้

/backend/sales/invoicesงานขาย/การเงิน

ติดตามอายุหนี้ (aging) การเก็บเงิน และความพร้อมของเอกสารภาษี

  • การ์ดสรุป: ยอดค้างชำระทั้งหมด, ใกล้ครบกำหนด (7 วัน), ยอดใกล้ครบกำหนด, เกินกำหนด
  • คอลัมน์: เลขที่, วันที่, ครบกำหนด, ลูกค้า, ประเภทเอกสาร, ยอดรวม, ชำระแล้ว, คงค้าง, สถานะ (เกินกำหนด)
  • ปุ่มในแต่ละแถว: ดู 👁, พิมพ์ 🖨, บันทึกรับชำระ 💲, ยกเลิก 🚫

9.Shipment Jobs

/backend/shipmentsชิปเมนต์

10.Reports

  1. เลือกประเภทรายงานจาก dropdown Report (เช่น Shipment jobs by date)
  2. กำหนด Date From – Date To

หมวด Finance

วงจรเบิกเงินทดรอง (Cash Request) หน้าเบิกเงิน/อนุมัติ/จ่าย/เคลียร์ ใช้ชุดสถานะร่วมกัน: ร่าง → รออนุมัติ → อนุมัติแล้ว → บัญชีรอยืนยันยอด → ยืนยันยอดแล้ว → จ่ายเงินแล้ว → เคลียร์บางส่วน → เคลียร์แล้ว (และ ยกเลิก). ทุกหน้ามีการ์ดสรุป 4 ใบ (รายการตามตัวกรอง / ยอดขอเบิก / ยอดอนุมัติ-จ่ายแล้ว / ยอดค้างเคลียร์) และตัวกรองเหมือนกัน (Shipment, ค้นหา, ลูกค้า, ต้องใช้เงินตั้งแต่–ถึงวันที่). เลขคำขอขึ้นต้นด้วย PCR

11.Expenses — นำเข้าค่าใช้จ่าย (OCR)

/backend/expensesOCR

อัปโหลดเอกสารค่าใช้จ่าย แล้วให้ระบบอ่านข้อมูลอัตโนมัติด้วย OCR (OpenAI)

  1. กด Choose File เลือกไฟล์ (รองรับ PDF/JPG/PNG/WEBP/TXT/CSV ขนาดไม่เกิน 20MB)
  2. เปิดสวิตช์ Auto OCR เพื่อให้ระบบอ่านข้อมูลอัตโนมัติ
  3. กด Upload — เอกสารจะเข้าคิว Imported Documents (OCR Queue)
  4. ตรวจผล OCR ในตาราง (VENDOR, DOC NO, DATE, TOTAL, ITEMS, CONFIDENCE) แล้วยืนยันเป็น draft ค่าใช้จ่าย

12.Tax Documents — ใบเสร็จ/ใบกำกับภาษี

/backend/sales/tax-documentsเอกสารภาษี

รวมเอกสารภาษีที่ออกแล้ว พร้อมสรุปยอดและ VAT

  • ปุ่มช่วงเวลา: เดือนนี้ / เดือนก่อน / 3 เดือนย้อนหลัง / ปีนี้ / ทั้งหมด
  • ตัวกรอง: เดือน, ตั้งแต่วันที่–ถึงวันที่, ประเภทเอกสาร, ลูกค้า
  • การ์ดสรุป: เอกสารทั้งหมด, ยอดรวม, ภาษีมูลค่าเพิ่ม (VAT), ใบแจ้งหนี้/ใบกำกับภาษี, ใบเสร็จ/ใบกำกับภาษี, ใบเสร็จรับเงิน
  • คอลัมน์: เลขที่เอกสาร, วันที่, ประเภท, ลูกค้า, เลขผู้เสียภาษี, ยอดเงิน, VAT, อ้างอิง

13.เบิกเงิน — Cash Request Intake

/backend/finance/cash-requests/intakeการเงิน

เตรียมและส่งคำขอเบิกเงินทดรองสำหรับงาน Shipment

  1. สร้างคำขอเบิก โดยผูกกับงาน Shipment (Job/BL/Booking/Quotation) และระบุรายการที่จะใช้เงิน
  2. ตรวจสถานะผ่านแท็บ: ร่าง / รออนุมัติ / บัญชีรอยืนยันยอด / ทั้งหมด
  3. เมื่อพร้อมส่ง คำขอจะเข้าสู่ขั้นตอน อนุมัติเงิน ต่อไป

14.อนุมัติเงิน — Money Approvals

34.Document Statuses — จัดการสถานะเอกสาร

/backend/settings/system/document-statuses

กำหนดชื่อ สี และลำดับของสถานะ แยกตามประเภทเอกสาร

  1. เลือกประเภทเอกสาร: ใบเสนอราคา / ใบสั่งขาย / ใบแจ้งหนี้
  2. เพิ่มสถานะใหม่ผ่านฟอร์ม: status_key (ใช้ a–z, 0–9, _), ชื่อแสดงผล, สี, ลำดับ, เปิดใช้งาน
  • ใบเสนอราคา: แบบร่าง, ส่งแล้ว, อนุมัติ, ปฏิเสธ, หมดอายุ, สร้างใบสั่งขายแล้ว
  • ใบสั่งขาย: แบบร่าง, ยืนยัน, กำลังดำเนินการ, จัดส่งแล้ว, ส่งถึงแล้ว, ยกเลิก
  • ใบแจ้งหนี้: แบบร่าง, ส่งแล้ว, ชำระบางส่วน, ชำระแล้ว, เกินกำหนด, ยกเลิก
ข้อควรระวังสถานะหลักของระบบ (core status) ลบไม่ได้ แต่แก้ชื่อ/สี/เปิด-ปิดได้
